# Deviation Bank

Tracks a FedEx pilot's deviation bank under the 2026 CBA, Section 8.C: deadhead credits, deviation spending, the 3-bid-period DBA carryover, the 50% move to the HAC bank, and the HAC bank itself.

Live at https://gk9tzsb8jy-lang.github.io/deviation-bank/

Open it in Safari on the iPad, then Share > Add to Home Screen. It works offline. Data stays on the device; use Setup & backup > Copy backup now and then. When you change `index.html`, bump `VERSION` in `sw.js` so iPads pick up the new copy.
